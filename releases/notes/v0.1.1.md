Skyrim Mod Loader 0.1.1 adds toast notifications for completed actions.

**What's new**

- Toast notifications when an action finishes: deploy and force full redeploy, delete mod, install archive, import failure, and Save ESP Order.
- Toasts are one-shot events consumed after they are shown, so they do not repeat on recomposition.

**Install**

Download `SkyrimModLoader-v0.1.1.apk` and install it over the existing app. Android 11 (API 30) or newer.
