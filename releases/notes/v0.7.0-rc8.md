# Droid Mod Loader v0.7.0-rc8

## Skyrim Legendary Edition plugin management and port sync

This release completes the Skyrim Legendary Edition port of Droid Mod Loader.
Game profiles other than Skyrim Legendary Edition have been removed, and the
plugin workflow now mirrors the Mods dashboard so ESPs can be edited live and
persisted through the port folder.

## Added

- **Editable ESP list.** Plugins can be enabled or disabled and reordered with
  Up and Down from the ESP card, like the mods list. Locked official Skyrim
  masters stay pinned at the top and cannot be moved or disabled.
- **Save ESP Order.** Writes pending ESP changes to the port folder:
  `Plugins.txt` receives the enabled plugins and `loadorder.txt` receives the
  full plugin order. Internal plugin state is synced and the dashboard refreshes
  after saving.
- **Automatic port folder detection.** The port folder is read from
  `<game root>/port`, specifically
  `<port>/save/AppData/Local/Skyrim/Plugins.txt` and
  `loadorder.txt`, on startup and after profile, game, or target changes.
- **Plugin reconciliation after installs, removals, deploys and redeploys.**
  Normal Deploy now calls `syncPlugins()`, matching Force Full Redeploy.
  Installs, removals, mod enable/disable changes and reorders all reconcile the
  plugin list. Port plugin files are updated when the plugin membership changes,
  so removed ESPs no longer linger as active after a deploy.
- **Updated launcher icon.** Uses `icon-dml.png`/`icon-dml.svg` as the icon
  source, with a white adaptive icon background and legacy/mipmap icons that
  mirror their corresponding mipmap icons. The dashboard header card no longer
  shows the app icon beside the app name.
- **Release artifacts.** Version `v0.7.0-rc8` with `versionCode=11`. Release APK
  published as `DroidModLoader-v0.7.0-rc8.apk` on GitHub as a prerelease.

## Changed

- The dashboard header shows the app name and version without the app icon.
- Plugin save flow writes port `Plugins.txt` (enabled plugins only) and
  `loadorder.txt` (full order) on Save ESP Order, and reconciles port files
  whenever the plugin set changes during installs, deploys, removals and enable/
  disable edits.
- Port file reconciliation preserves existing port order and active flags when
  the plugin membership is unchanged, so ordinary startup and refresh syncs do
  not rewrite the user's port files.
- Normal Deploy and Force Full Redeploy both sync plugins after deployment.

## Fixed

- ESP cards kept showing plugins whose source mod was removed after deploy or
  removal. Deploy now reconciles the plugin list and updates port files so
  removed ESPs disappear immediately.
- Skyrim-only scope was not enforced; Oblivion, Fallout 3, Fallout: New Vegas,
  Tale of Two Wastelands and Fallout 4 plugin rules were removed.

## Known Issues

- Beta software: back up game folders before deploying.
- Physical deployment requires an Android 11+ device with all files access.
- Android may block access to another application's protected `Android/data`
  directory even when all files access is enabled.

## Upgrade Notes

- Install `v0.7.0-rc8` over `v0.7.0-beta` without uninstalling first to retain
  profiles and state managed by DML.
- Grant all files access when prompted on Android 11 or newer.
