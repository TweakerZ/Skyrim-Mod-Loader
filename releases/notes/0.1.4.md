# Skyrim Mod Loader 0.1.4

## Stable release

A shared Material You design system, a new launcher icon, and a light/dark
native window.

## About

Skyrim Mod Loader (SML) is a Skyrim Legendary Edition fork of Droid Mod Loader
(DML) for the Skyrim static Android port created by
https://github.com/ttom795/Skyrim_Android/.

DML (by CyberShonk) manages Bethesda game mods for Windows compatibility
environments hosted on Android, such as Winlator and GameHub. SML is a fork of
DML and is not DML itself.

## What's new

- The app now draws with the shared `skyrim-suite-ui` Material You design
  system, the same look used by the other Skyrim-on-Android tools. Colours come
  from your wallpaper on Android 12 and later, with a matching light and dark
  fallback scheme on older devices. The old fixed Carbon Red, Pip Boy, Nordic,
  Oblivion and FNV palettes are no longer used for the live UI.
- New launcher icon, including background, foreground and monochrome layers for
  themed icons.
- The native window and system bars follow the system light and dark mode
  instead of the old near-black frame, so the cold-start screen no longer
  flashes dark on a light theme.
- Removed the obsolete Fullscreen button from the Mods card. The fullscreen mods
  and plugins views were already gone, so the button did nothing.

## Included from earlier releases

- FOMOD installer options show their preview image when the installer provides
  one, resolved case-insensitively and decoded off the main thread.
- Disable All Mods and Enable All Mods buttons under Import Mod Archives, each
  keeping the current load order and syncing plugins.
- A progress bar under Deploy that runs while deploying or installing, with a
  status line for the current operation and queued imports.
- Set a mod load position from the mods list: type a position from `001` through
  the current last mod and tap **Set**.
- Toast notifications for deploy, force full redeploy, delete mod, install
  archive, import failure, and Save ESP Order.
- Editable ESP list: enable/disable plugins and reorder with Up/Down from the
  dashboard. Locked official Skyrim masters stay pinned at the top.
- Save ESP Order writes pending changes to the port folder: `Plugins.txt`
  (enabled plugins) and `loadorder.txt` (full order).
- Automatic Skyrim port folder detection at `<game root>/port`
  (`<port>/save/AppData/Local/Skyrim/`).
- Plugin reconciliation after installs, removals, mod enable/disable changes,
  normal deploys and full redeploys.
- Companion app: [LOOT Android](https://github.com/TweakerZ/loot-android) for
  LOOT-based plugin load-order sorting. It reads and writes the same
  `Plugins.txt` and `loadorder.txt` that SML manages.
