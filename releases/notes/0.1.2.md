Skyrim Mod Loader 0.1.2 adds mod load position control and toast notifications, and drops the leading `v` from version labels.

**What's new**

- Set a mod load position from the mods list: type a position from `001` through the last mod and tap **Set**. The mod moves there and the mods after it shift down by one.
- The position field uses the same height as the Up, Down and Set buttons.
- Toast notifications for deploy, force full redeploy, delete mod, install archive, import failure, and Save ESP Order.
- Version labels no longer use a leading `v`; this release reports `0.1.2`.

**Install**

Download `SkyrimModLoader-0.1.2.apk` and install it over the existing app. Android 11 (API 30) or newer.
