Skyrim Mod Loader 0.2.0 switches profiles cleanly and manages their files.

**What's new**

- Switching a profile saves the current profile, clears its deployment, then restores and deploys the selected profile.
- Creating a profile clears the previous deployment and deploys the new profile.
- Manage Profiles shows each profile as a card with its details, Switch and Delete actions.
- Deleting a profile asks for confirmation and removes its installed mods and saved state. The active profile cannot be deleted.
- The dashboard locks while a profile switch, create or delete is running.
- Report & Diagnostics and Recent Activity start collapsed.
- The interface uses the Skyrim Mod Loader name throughout.
- Removed the Play button and the second-screen toggle.

**Install**

Download `SkyrimModLoader-0.2.0.apk` and install it over the existing app. Android 11 (API 30) or newer.
