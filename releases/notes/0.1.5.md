Skyrim Mod Loader 0.1.5 centres the header and keeps the action bar above the keyboard.

**What's new**

- The header is centred and reads **Skyrim Mod Loader**. The launcher label uses the same name.
- The action bar follows the keyboard inset, so **Import Mods**, **Profiles** and **Deploy Mods** stay above the keyboard instead of leaving a blank gap.

**Install**

Download `SkyrimModLoader-0.1.5.apk` and install it over the existing app. Android 11 (API 30) or newer.
