# Skyrim Mod Loader 0.1.5

## Stable release

A centered header and an action bar that stays above the keyboard.

## About

Skyrim Mod Loader (SML) is a Skyrim Legendary Edition fork of Droid Mod Loader
(DML) for the Skyrim static Android port created by
https://github.com/ttom795/Skyrim_Android/.

DML (by CyberShonk) manages Bethesda game mods for Windows compatibility
environments hosted on Android, such as Winlator and GameHub. SML is a fork of
DML and is not DML itself.

## What's new

- The header is centred on the screen again. The old app bar centred the title
  in the space left over by the settings button, which pushed a long name to the
  left, and the full name no longer fit without being clipped. The app is now
  titled **Skyrim Mod Loader** in both the header and the launcher label.
- Opening the keyboard no longer leaves a blank gap above it. The action bar
  now follows the keyboard inset, so **Import Mods**, **Profiles** and **Deploy
  Mods** lift above the keyboard instead of staying hidden behind it, and the
  scrolling body is no longer padded twice.

## Included from earlier releases

- Shared `skyrim-suite-ui` Material You design system with wallpaper-based
  dynamic colour and matching light and dark fallback schemes.
- New launcher icon, including background, foreground and monochrome layers for
  themed icons.
- The native window and system bars follow the system light and dark mode.
- FOMOD installer options show their preview image when the installer provides
  one.
- Disable All Mods and Enable All Mods buttons under Import Mod Archives.
- A progress bar under Deploy that runs while deploying or installing.
- Set a mod load position from the mods list from `001` through the last mod.
- Toast notifications for deploy, force full redeploy, delete mod, install
  archive, import failure, and Save ESP Order.
- Editable ESP list with Up/Down reordering, and locked official Skyrim masters
  pinned at the top.
- Save ESP Order writes `Plugins.txt` (enabled plugins) and `loadorder.txt`
  (full order) to the port folder.
- Automatic Skyrim port folder detection at `<game root>/port`.
- Plugin reconciliation after installs, removals, mod enable/disable changes,
  normal deploys and full redeploys.
- Companion app: [LOOT Android](https://github.com/TweakerZ/loot-android) for
  LOOT-based plugin load-order sorting. It reads and writes the same
  `Plugins.txt` and `loadorder.txt` that SML manages.
