Skyrim Mod Loader 0.1.3 adds FOMOD option images, bulk mod toggles and a deploy progress bar.

**What's new**

- FOMOD installer options show their preview image when the installer provides one.
- Disable All Mods and Enable All Mods buttons under Import Mod Archives, each keeping the current load order and syncing plugins.
- A progress bar under Deploy while deploying or installing, with a live status line and queued import count.

**Install**

Download `SkyrimModLoader-0.1.3.apk` and install it over the existing app. Android 11 (API 30) or newer.
