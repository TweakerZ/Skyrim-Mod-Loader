# Skyrim Mod Loader 0.1.3

## Stable release

FOMOD option images, Disable All / Enable All mod buttons, and a deploy and
install progress bar.

## About

Skyrim Mod Loader (SML) is a Skyrim Legendary Edition fork of Droid Mod Loader
(DML) for the Skyrim static Android port created by
https://github.com/ttom795/Skyrim_Android/.

DML (by CyberShonk) manages Bethesda game mods for Windows compatibility
environments hosted on Android, such as Winlator and GameHub. SML is a fork of
DML and is not DML itself.

## What's new

- FOMOD installer options now show their preview image when the installer
  provides one. Images are resolved case-insensitively against the extracted
  archive and the `fomod/` folder, decoded off the main thread, scaled down and
  cached, and skipped cleanly when missing or in an unsupported format.
- Disable All Mods and Enable All Mods buttons sit side by side under Import
  Mod Archives. Each keeps the current load order and syncs plugins.
- A progress bar appears under Deploy Mods while deploying or installing, with a
  live status line that shows the current operation and queued archive imports.

## Included from earlier releases

- Set a mod load position from the mods list: in the expanded mod row, type a
  position from `001` through the current last mod and tap **Set**. The mod is
  placed at that position and the mods after it shift down by one.
- Toast notifications for deploy, force full redeploy, delete mod, install
  archive, import failure, and Save ESP Order.
- Editable ESP list: enable/disable plugins and reorder with Up/Down from the
  dashboard. Locked official Skyrim masters stay pinned at the top.
- Save ESP Order writes pending changes to the port folder:
  `Plugins.txt` (enabled plugins) and `loadorder.txt` (full order).
- Automatic Skyrim port folder detection at `<game root>/port`
  (`<port>/save/AppData/Local/Skyrim/`).
- Plugin reconciliation after installs, removals, mod enable/disable changes,
  normal deploys and full redeploys.
- Companion app: [LOOT Android](https://github.com/TweakerZ/loot-android) for
  LOOT-based plugin load-order sorting. It reads and writes the same
  `Plugins.txt` and `loadorder.txt` that SML manages.
