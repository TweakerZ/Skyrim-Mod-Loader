Skyrim Mod Loader 0.1.6 turns the app into the hub for the Skyrim Android suite and shows which mods overwrite each other.

**What's new**

- **Advanced settings > Companion apps** lists Anim Tool, Body Tool, LOOT Android and ReSaver with their real icons and opens them in place. The four tools no longer add launcher icons, so this section is the only place they appear.
  - [Anim Tool](https://github.com/TweakerZ/skyrim-anim-tool) builds FNIS animation behaviour.
  - [Body Tool](https://github.com/TweakerZ/skyrim-body-tool) builds BodySlide outfits and bodies.
  - [LOOT Android](https://github.com/TweakerZ/loot-android) sorts the plugin load order.
  - [ReSaver](https://github.com/TweakerZ/resaver-android) cleans stale script data from saves.
- Mods now report file overlaps. Expand a mod to read the names of the mods it overwrites or is overwritten by; collapsed rows carry `↑` and `↓` badges with a file count.
- View Files folder rows name the mod that overwrites the folder.

**Install**

Download `SkyrimModLoader-0.1.6.apk` and install it over the existing app. Android 11 (API 30) or newer.
