Skyrim Mod Loader 0.1.8 imports more archives: repeated folder entries, unreadable FOMOD configs, and selections that match no files now install instead of stopping.

**What's new**

- A `ModuleConfig.xml` that cannot be read no longer fails the import. The archive installs as plain files, and the installer dialog says the FOMOD options were skipped.
- A FOMOD selection that resolves to no files installs the extracted files instead of stopping.
- Configs written in Windows-1252 or Windows-1251 are decoded by matching their source paths against the archive, so accented and Cyrillic file names resolve.
- Installer references to files that are not in the archive are reported after the install instead of only appearing in the debug log.
- A `fomod` folder with no usable `ModuleConfig.xml` now produces a warning.
- Repeated archive entries no longer stop the import with a conflicting-paths error. Some RAR installers, including LeatherBackpack, list the same folder dozens of times.
- A repeated file entry keeps the last copy, the same way Windows extractors behave. Folder entries are created once and reused.

**Install**

Download `SkyrimModLoader-0.1.8.apk` and install it over the existing app. Android 11 (API 30) or newer.
