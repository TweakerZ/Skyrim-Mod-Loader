Skyrim Mod Loader 0.1.8 lets archives install when they repeat a folder or a file entry.

**What's new**

- Repeated archive entries no longer stop the import with a conflicting-paths error. Some RAR installers, including LeatherBackpack, list the same folder dozens of times.
- A repeated file entry keeps the last copy, the same way Windows extractors behave. Folder entries are created once and reused.

**Install**

Download `SkyrimModLoader-0.1.8.apk` and install it over the existing app. Android 11 (API 30) or newer.
