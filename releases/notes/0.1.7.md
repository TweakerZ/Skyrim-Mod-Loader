Skyrim Mod Loader 0.1.7 fixes two archive imports that stopped with an error.

**What's new**

- FOMOD installers whose `ModuleConfig.xml` starts with a UTF-8 byte order mark now install. This covers Bijin Family Bodyslides and other older FOMOD archives.
- Archives that ship the same folder in two letter cases, such as `meshes` and `Meshes`, now merge into one folder. Files from both are kept, and a later file replaces an earlier one that resolves to the same path.

**Install**

Download `SkyrimModLoader-0.1.7.apk` and install it over the existing app. Android 11 (API 30) or newer.
