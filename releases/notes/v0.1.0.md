Skyrim Mod Loader 0.1.0 is the first stable release: a Skyrim Legendary Edition fork of Droid Mod Loader for the Skyrim static Android port.

**What's new**

- Editable ESP list: enable or disable plugins and reorder them with Up/Down from the dashboard. Locked official Skyrim masters stay pinned at the top.
- Save ESP Order writes pending changes to the port folder: `Plugins.txt` (enabled plugins) and `loadorder.txt` (full order).
- Automatic port folder detection at `<game root>/port`.
- Plugin reconciliation after installs, removals, mod toggles, normal deploys and full redeploys.
- Updated launcher icon with a white adaptive background.
- Companion app: [LOOT Android](https://github.com/TweakerZ/loot-android) sorts plugin load order using the same `Plugins.txt` and `loadorder.txt`.

**Install**

Download `SkyrimModLoader-v0.1.0.apk` and install it. Android 11 (API 30) or newer.
